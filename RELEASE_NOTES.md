# Klyra 1.8-klyra.7

Android build 30 · Windows package 1.8.32

- Visible playlist Save and Download buttons next to playback controls.
- Whole-playlist collection before downloading, with progress and failures in Downloads.
- Removed the sidebar sign-in card. Account management stays in Settings.
- Clear email-confirmation instructions and resend; periodic Klyra library sync.
- Klyra update notices with verified downloads and user-confirmed installation.
- Optional Android immersive cover screen in Settings > Appearance: large artwork,
  gentle motion and real session controls. Open it before locking; your device security
  remains enabled. System lock-screen layouts still depend on Android and your phone.
- Existing Liquid Glass styling, playback and library storage retained.

Install this version over the existing app once; do not uninstall first. Windows
portable users can move to Setup, which retains Klyra's existing account data location.
Close any old portable copy before starting the installed version. Android requires
the same existing signing key for an in-place update.

The update channel only considers published, non-prerelease versions. This release
contains the updater; a newer published version is needed to see its update prompt.
Provider playback/download availability varies. Hardware installation, full live
account sync and a real future-release update cycle have not been verified here.
See KLYRA_TEST_REPORT.md for the exact checks and limitations.

Klyra is a modified GPLv3 derivative of BitChord. Corresponding source and license
notices are included; the source ZIP contains the exact application changes used
for these binaries, even if the release tag's code snapshot predates the local build.
